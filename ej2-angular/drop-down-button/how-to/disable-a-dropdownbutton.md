# How to disable a Dropdown Menu in Angular Dropdown Menu

Angular Dropdown Menu component can be enabled/disabled by giving [`disabled`](https://ej2.syncfusion.com/angular/documentation/api/drop-down-button/index-default#disabled) property.
To disable Angular Dropdown Menu component, the disabled property can be set as `true`.
