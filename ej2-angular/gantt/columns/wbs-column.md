# Work Breakdown Structure (WBS) in Angular Gantt Chart Component

The Work Breakdown Structure (WBS) organizes project tasks hierarchically by assigning unique codes to each task. This improves task visibility and management, especially in large-scale construction or enterprise-level software projects.

## Configuration and implementation

To enable WBS in the Gantt Chart component:

- **Enable WBS Codes**: Set [enableWBS](https://ej2.syncfusion.com/angular/documentation/api/gantt#enablewbs) to **true**  to automatically generate unique task codes and define their predecessors.
- **Auto-Update Codes**: Set [enableAutoWbsUpdate](https://ej2.syncfusion.com/angular/documentation/api/gantt#enableautowbsupdate) to **true** to maintain accurate WBS codes during operations such as sorting, editing, or drag-and-drop.

> When the WBS column is enabled in the Angular Gantt Chart using the [enableWBS](https://ej2.syncfusion.com/angular/documentation/api/gantt#enablewbs) property set to **true**, the default **ID** and **Predecessor** columns are automatically disabled, as the WBS Code and WBS Predecessor columns already display the ID and predecessor values based on the task hierarchy. The WBS column fields must include both **WBS Code** and **WBS Predecessor** in the [taskFields](https://ej2.syncfusion.com/angular/documentation/api/gantt/taskFields) configuration.

## Managing WBS code updates

This is especially useful during operations like row drag-and-drop, where auto-update is triggered only during that specific action to ensure efficient and accurate code handling.

## Limitations

The WBS feature has the following limitations in the Gantt Chart component:

* **No Inline Editing**: Editing of the WBS Code and WBS Predecessor columns is not supported. These columns are read-only and are automatically calculated based on the task hierarchy.

* **No Load on Demand**: Load on demand (virtual loading of data) is not supported with the WBS feature. You must load all tasks upfront to ensure the WBS hierarchy is properly calculated.

* **No Direct Field Mapping**: WBS Code and WBS Predecessor fields cannot be mapped directly from the data source. These values are automatically generated by the Gantt Chart based on the parent-child task relationships defined in the data.

These limitations ensure the accuracy and consistency of the WBS hierarchy. If you need editable ID or predecessor columns, consider using custom ID and predecessor columns instead of the WBS feature.
