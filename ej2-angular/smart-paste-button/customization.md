# Customization in Angular Smart Paste Button

The Syncfusion<sup style="font-size:70%">®</sup> Angular Smart Paste Button component fully inherits all the properties, types, and styling options of the Syncfusion<sup style="font-size:70%">®</sup> Angular Button component. This allows you to use the same appearance, behavior, and customization features available in the standard Angular Button while benefiting from the AI-powered Smart Paste functionality.

The Smart Paste Button supports a wide range of customization options, enabling you to seamlessly integrate it into your application's design and workflow.

## Key Benefits of using Smart Paste Button

* Supports all standard Button component features, including appearance customization, icons, sizing options, and styling.
* Uses the same APIs and configuration patterns as the Syncfusion&lt;sup style="font-size:70%"&gt;&reg;&lt;/sup&gt; angular Button component, making it easy to integrate into existing applications.
* Maintains a consistent look and behavior across your application without requiring additional customization.
* Improves user productivity by intelligently extracting information from pasted content and automatically populating relevant form fields.
* Allows Smart Paste functionality to be added to existing button implementations with minimal changes.
* Combines familiar button capabilities with AI-powered form-filling assistance to deliver a seamless user experience.

For more information about the customization options inherited from the Angular Button component, refer to the following documentation:

* [Types and Styles](https://ej2.syncfusion.com/angular/documentation/button/types-and-styles)
* [Appearance](https://ej2.syncfusion.com/angular/documentation/button/how-to/customize-button-appearance)
