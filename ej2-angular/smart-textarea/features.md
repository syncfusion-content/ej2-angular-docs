# Features in Angular Smart TextArea

The Syncfusion<sup style="font-size:70%">®</sup> Angular Smart TextArea component inherits all the properties, features, methods, events, and styling capabilities of the Syncfusion<sup style="font-size:70%">®</sup> Angular TextArea component. This allows you to combine AI-powered text suggestions with the rich set of functionalities already available in the TextArea component.

You can use all standard TextArea features within the Smart TextArea without any additional configuration. The following sections provide links to the corresponding TextArea documentation for detailed information about each feature.

## Form Support

The Smart TextArea integrates seamlessly with Angular forms and supports both template-driven and reactive form validation scenarios. For more information, refer to the [Form Support](https://ej2.syncfusion.com/angular/documentation/textarea/form-support) documentation.

## Floating Labels

Floating labels improve form usability by displaying labels within the input area and automatically moving them above the component when users enter content or focus the control. For more information, refer to the [Floating Labels](https://ej2.syncfusion.com/angular/documentation/textarea/floating-label) documentation.

## Events

The Smart TextArea inherits all TextArea events, enabling you to respond to user interactions and component state changes. For more information, refer to the [Events](https://ej2.syncfusion.com/angular/documentation/textarea/events) documentation.

## Methods

You can perform component operations programmatically using the available TextArea methods. These methods help manage focus, state, and component behavior at runtime. For more information, refer to the [Methods](https://ej2.syncfusion.com/angular/documentation/textarea/methods) documentation.

## Style and Appearance

The Smart TextArea supports the same styling and appearance customization options as the TextArea component, allowing you to align it with your application's visual design. For more information, refer to the [Style and Appearance](https://ej2.syncfusion.com/angular/documentation/textarea/style-appearance) documentation.
